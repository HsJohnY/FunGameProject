## 风险与阻塞

- 游戏已确定采用 3D、固定第一人称、巨构维修概念和风暴荒原主题；渲染管线和完整业务架构仍需在需求基线后单独评估。
- 当前只要求内部内容易扩展，不将第三方 Mod 平台纳入 MVP。
- 好友互联网联机仍需技术验证，但不依赖 Steamworks、公开匹配或商业在线服务。
- 所有非 MVP 项已归入后续、明确不做或具体原型验证；不存在阻塞灰盒的产品决策。
