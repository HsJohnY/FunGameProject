# 好友联机与会话需求

状态：需求基线 v1.0；框架与中继供应商待技术验证

## 1. 联机定位

游戏面向 2–4 名固定好友，通过私密房间完成合作远征。MVP 使用监听主机，不建设专用服务器、公开匹配或商业反作弊系统。

- **SES-01（已确认，MUST）**：一名玩家同时作为游戏玩家和规则权威主机，其余玩家作为客户端。
- **SES-02（已确认，MUST）**：普通好友连接目标是“创建房间、获得短邀请码、输入邀请码加入”，不要求端口转发或 Steam 好友系统。
- **SES-03（MUST）**：本地开发保留同机多进程、局域网和显式 IP 入口，用于测试与故障排查，不作为普通玩家主流程。
- **SES-04（待技术验证）**：中继或打洞服务根据 Unity 版本兼容性、免费额度、网络表现、账号要求、可替换性和调试成本选型。

## 2. 会话流程

主菜单进入创建/加入房间，再进入 2–4 人大厅。大厅显示玩家身份、颜色、连接和准备状态，允许选择战役存档、当前任务与初始工具；全员准备后由房主开始。远征完成或失败后返回同一大厅。

- **SES-LOBBY-01（MUST）**：实现创建、加入、准备、取消准备、开局、离开和返回大厅。
- **SES-LOBBY-02（MUST）**：版本或内容清单不一致时阻止开局，并显示可理解原因。
- **SES-LOBBY-03（明确不做）**：MVP 不包含公开房间浏览器、快速匹配、平台好友列表或复杂房主管理。

## 3. 加入、断线与退出

- **SES-JOIN-01（已确认，MUST）**：MVP 只允许在大厅加入，不支持远征、Boss 或结算过程中途加入。
- **SES-RECON-01（已确认，LATER）**：完整远征中重连保留为后续候选，不进入 MVP。
- **SES-DISC-01（MUST）**：客户端断线时安全移除角色，主工具返回工具架，关键任务物返回恢复点，普通手持物落到有效位置。
- **SES-DISC-02（MUST）**：后续事件按剩余人数组织；当前事故不突然删除，但保留剩余玩家可完成路径。
- **SES-DISC-03（MUST）**：断线玩家可在本局结束后重新加入大厅。

## 4. 房主退出与存档

- **SES-HOST-01（已确认，MUST）**：MVP 不实现主机迁移；房主退出或断线会结束当前网络会话。
- **SES-HOST-02（MUST）**：客户端收到明确原因并安全返回主菜单或错误页，不停留在失去权威端的场景。
- **SES-HOST-03（MUST）**：战役保留到最近完成的安全站，未完成航程不结算永久成果。
- **SES-SAVE-01（已确认，MUST）**：战役存档由房主持有，MVP 不实现云同步。
- **SES-SAVE-02（MUST）**：战役存档支持校验、备份以及手动导出/导入，便于好友之间迁移房主。

## 5. 权威与表现

主机确认任务、故障、工具有效结果、物品归属、玩家/敌人状态、资源、奖励、随机种子和结算。客户端提交输入，并负责镜头、交互预览以及不改变规则结果的即时动画、音效、预测和插值。

- **SES-AUTH-01（MUST）**：客户端不得自行确认设备修复、资源消耗、奖励或任务完成。
- **SES-AUTH-02（MUST）**：权威拒绝客户端预测时立即校正，并提供足以理解失败原因的反馈。
- **SES-AUTH-03（MUST）**：内容位置与事故选择由主机产生并广播稳定 ID，不依赖客户端各自随机。

## 6. 同步预算

- **SES-SYNC-01（MUST）**：只同步具有玩法意义的状态，不逐帧同步装饰粒子、火花和小碎片。
- **SES-SYNC-02（MUST）**：大型任务零件同步位置、持有者、安装和恢复状态，并限制同时活跃的网络物理对象数量。
- **SES-SYNC-03（MUST）**：故障同步阶段、关键参数、玩家操作和恢复结果；客户端根据这些状态本地表现视听效果。
- **SES-SYNC-04（MUST）**：每类网络对象明确生成、所有权、可写字段、销毁、断线和恢复规则。

## 7. MVP 验收

使用至少两个独立游戏进程验证：

- 创建、邀请码加入、准备、开局和返回大厅；
- 玩家移动、一个工具、一个共享任务零件和一条故障链；
- 玩家倒地与队友救援；
- 成功、失败、客户端退出和房主退出；
- 断线后的工具、任务物和事故可完成性恢复；
- 人为延迟、抖动和丢包下核心状态仍可理解；
- 网络日志能够通过会话、玩家和对象 ID 定位不一致。

## 8. 延后或排除

后续候选：远征中途加入、短暂断线重连、共享/云端战役存档和主机迁移。

当前排除：Steamworks、公开匹配、专用服务器、跨平台、商业反作弊、举报/封禁平台和持续运行后端。
