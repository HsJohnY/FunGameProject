# 支持模式与沟通需求

状态：MVP 单人/文字边界及后续语音方向已确认 v0.1

## 1. 正式远征与单人边界

- **SUP-SOLO-01（已确认，MUST）**：正式远征按 2–4 人设计，MVP 开局最低人数为 2。
- **SUP-SOLO-02（已确认，MUST）**：MVP 不提供完整单人战役，也不制作 AI 队友。
- **SUP-SOLO-03（LATER）**：正式单人远征保留为后续候选；若加入，必须单独解决协作、搬运、倒地、并行事故和信息分散，不以简单降低数值代替适配。
- **SUP-SOLO-04（MUST）**：核心规则和内容必须能由开发测试入口在单进程中启动、复位和观察，不要求每次基础验证都召集第二名玩家。

## 2. 单人训练舱

巨构内部提供一个安全训练舱，兼作新手教学、操作设置验证和基础内容测试。

- **TRN-01（已确认，MUST）**：训练舱允许单人进入，包含移动/观察、上下文拾取与放置、三种工具各一个安全目标、一个小型零件安装和一个不会恶化的简化故障。
- **TRN-02（MUST）**：提供明显且可重复使用的重置操作，不消耗战役资源或影响永久进度。
- **TRN-03（MUST）**：训练舱不包含完整远征结算、正式战斗、成长奖励、剧情分支或单人难度平衡。
- **TRN-04（SHOULD）**：设置或输入改变后可直接在训练舱验证，无需重新开始游戏。

## 3. MVP 文字聊天

- **CHAT-01（已确认，MUST）**：MVP 包含好友房文字聊天，在大厅和远征中使用同一个队伍频道。
- **CHAT-02（MUST）**：消息显示发送者名称、玩家颜色和正文；系统消息使用不同样式，不冒充玩家消息。
- **CHAT-03（MUST）**：支持中文输入法、常用复制粘贴、发送、取消和有限会话历史。
- **CHAT-04（MUST）**：输入框聚焦时暂停本地移动、工具和上下文操作输入；发送或取消后可靠恢复游戏输入。
- **CHAT-05（MUST）**：倒地玩家仍可使用文字聊天。
- **CHAT-06（已确认）**：MVP 不实现敏感词过滤、举报、封禁或公开社区治理。
- **CHAT-07（MUST）**：即使不做内容过滤，主机仍验证消息长度、发送频率、编码及富文本/控制字符，避免 UI 注入、刷屏和异常网络负载。
- **CHAT-08（MUST）**：聊天记录只存在于当前会话内，不写入战役存档或外部日志正文。

## 4. 智能标记

- **PING-01（已确认，MUST）**：保留单一智能标记输入，根据准星目标标记故障、设备、零件、敌人或普通位置。
- **PING-02（MUST）**：标记携带玩家身份、稳定目标 ID、方向和短暂空间提示，不要求复杂指令轮盘。
- **PING-03（MUST）**：标记是文字和语音的补充，不能替玩家自动完成全部信息推理。
- **PING-04（MUST）**：标记频率受限，旧标记自动过期，避免遮挡和网络刷屏。

## 5. 内置语音与距离语音

- **VOICE-01（已确认，POST-MVP MUST）**：正式游戏后续版本需要内置语音系统和远征中的距离语音；该目标不阻塞首个 MVP。
- **VOICE-02（MUST）**：后续语音至少提供麦克风设备选择、输入状态、按键说话/开放麦选项、静音、单人音量和总音量控制。
- **VOICE-03（MUST）**：大厅使用全队语音；远征根据玩家距离进行空间定位和衰减，最大距离与遮挡规则在语音原型中确认。
- **VOICE-04（MUST）**：语音故障或权限被拒绝不能阻止加入房间，文字聊天与智能标记保持可用。
- **VOICE-05（MUST）**：语音服务、隐私提示、带宽、编解码、区域可用性和费用必须在后续选型前重新调研。
- **VOICE-06（明确不做于 MVP）**：首个 MVP 使用外部语音作为可选补充，不实现内置采集、传输、录制或转写。

## 6. 开发测试工具

- **DEV-01（MUST）**：开发构建支持重置事故、选择种子、模拟人数配置、传送、强制倒地/恢复和查看权威网络状态。
- **DEV-02（MUST）**：延迟、抖动和丢包模拟可以通过测试配置启用。
- **DEV-03（MUST）**：测试入口不参与战役进度或正常任务奖励，并在可分享构建中默认关闭。
- **DEV-04（MUST）**：测试工具通过明确的开发程序集或编译条件隔离，不能仅依赖隐藏按钮保障不可用。

## 7. MVP 验收

- 单人在训练舱完成三种工具和基本交互练习；
- 正式远征无法在少于两人时误开局，并解释原因；
- 两个真实进程能在大厅和远征中交换中文消息；
- 聊天输入不会同时触发移动、工具或快捷键；
- 超长、过快或包含异常富文本的消息被安全处理；
- 倒地玩家能通过聊天和标记继续提供信息；
- 关闭外部语音后，测试者仍能用文字与标记完成基础任务；
- 可分享构建中不能正常访问开发测试入口。
