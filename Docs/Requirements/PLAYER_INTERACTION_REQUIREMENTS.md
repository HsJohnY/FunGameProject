# 玩家视角、移动与交互需求

状态：第一人称与简化输入原则已确认 v0.1；具体移动参数待原型

## 1. 视角

- **PLY-VIEW-01（已确认，MUST）**：游戏固定使用第一人称作为实际操作视角。
- **PLY-VIEW-02（MUST）**：不同时维护可切换的第三人称玩法模式。
- **PLY-VIEW-03（MUST）**：队友在第一人称下仍具有清晰颜色、名称、轮廓、动作和工具状态。
- **PLY-VIEW-04（MUST）**：巨构运动主要通过环境、音频和低频反馈表达，不持续摇晃镜头。
- **PLY-VIEW-05（SHOULD）**：提供视野范围、镜头晃动、动态模糊和必要晕动设置。

## 2. 输入复杂度原则

- **PLY-IN-01（已确认，MUST）**：不因查看、拾取、携带、放置、插入和操作等细分行为分别增加大量按键。
- **PLY-IN-02（已确认，MUST）**：在同一时刻互斥、且玩家意图可由上下文可靠判断的行为复用同一个逻辑输入。
- **PLY-IN-03（MUST）**：输入绑定基于少量“玩家意图”，而不是为每个对象类型定义独立按键。
- **PLY-IN-04（MUST）**：上下文动作执行前显示将要发生的行为和目标。
- **PLY-IN-05（MUST）**：当多个上下文动作同时可能成立时，使用公开、稳定且可测试的优先级，不允许随机或依赖场景对象顺序。
- **PLY-IN-06（MUST）**：具有重大或不可逆后果的动作不能因上下文误判立即执行，应采用长按确认、二次确认或专用安全条件。
- **PLY-IN-07（SHOULD）**：正式版本支持键鼠重绑定；控制器映射在 MVP 前验证。

## 3. 逻辑动作集合

当前建议的最小逻辑动作：

| 逻辑动作 | 用途 |
| --- | --- |
| 移动/观察 | 角色移动和镜头 |
| 上下文交互 | 拾取、放置、插入、拔出、启动、救援等互斥操作 |
| 工具主要功能 | 当前工具的主要维修或防卫动作 |
| 工具次要功能 | 当前工具的替代模式或辅助动作 |
| 丢下/取消 | 放弃当前持有物或退出当前连续操作 |
| 跳跃/跨越 | 基础垂直移动 |
| 冲刺 | 短时间快速移动 |
| 蹲伏 | 通过低矮空间和稳定操作姿态 |
| 标记 | 向队友标记对象、位置或危险 |
| 菜单 | 暂停、设置、任务和必要界面 |

这不是最终键位表。若原型证明某项动作可以可靠合并，应继续减少；若合并导致频繁误操作，才允许拆分。

## 4. 上下文交互规则

建议由单一“上下文交互”表达：

- 空手看向可携带物：拾取；
- 手持物看向有效安装位：放置或插入；
- 手持物无有效目标：不自动抛出，使用丢下/取消；
- 看向设备控制件：操作；
- 看向可救援队友：救援；
- 看向已连接且允许拆除的部件：拔出或解除；
- 对连续操作：按住同一交互输入持续执行，松开即停止。

“查看”默认通过靠近、准星聚焦和状态提示完成，不单独占用按键。只有确实需要放大、翻转或阅读的特殊物品，才进入短暂检查状态。

## 5. 上下文优先级基线

当目标重叠时，建议优先级为：

1. 紧急救援；
2. 当前任务物的有效放置/安装；
3. 当前正在进行的连续操作；
4. 设备操作；
5. 拾取普通物品；
6. 查看信息。

最终优先级必须通过实机测试确认。玩家可以移动准星改变目标，系统不得自动跨越明显距离选择其他对象。

## 6. 反馈要求

- 准星焦点显示对象名称、状态和当前动作；
- 可执行、条件不足、危险操作和其他玩家占用具有不同反馈；
- 无法操作时说明最主要原因，例如缺少工具、没有空间、系统仍带电或需要队友；
- 按住操作具有清晰过程反馈，但维修结果不能只由进度条表现；
- 网络权威拒绝操作时，客户端需要立即恢复并说明原因。

## 7. 移动能力建议

当前建议保留行走、短冲刺、蹲伏、普通跳跃、梯子、简单跨越、安全线、击退、倒地和救援。

暂不加入滑铲、翻滚、墙跑、自由攀爬、高速钩锁和复杂体力攀登。具体移动速度、加速度、空中控制、冲刺时长和跨越高度由灰盒原型确定。

## 8. 搬运要求

- 小型物品单人拾取、携带、放置和丢下；
- 大型物品允许单人缓慢拖动，两人正常搬运；
- 三至四人可以提高稳定性或并行处理，但不是主线硬门槛；
- 搬运重物时限制冲刺和部分工具操作；
- 任务关键物掉出场景时必须可恢复；
- 手持大型物品不得完全遮挡第一人称关键视野。

## 9. 原型验收

- 新玩家无需键位说明即可完成拾取、安装、操作和丢下；
- 同一上下文键在典型目标重叠场景中不会频繁误操作；
- 玩家在执行前能够说出按键会产生什么结果；
- 两名玩家可以完成大型零件搬运；
- 第一人称巨构运动不会造成持续明显不适；
- 键鼠核心玩法所需逻辑动作数量保持在可由普通玩家快速掌握的范围。
