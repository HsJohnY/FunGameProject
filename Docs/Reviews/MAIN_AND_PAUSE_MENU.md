# 主菜单、暂停菜单与设置接入说明

## 使用方式

- 玩家构建启动后显示主菜单，点击“开始维修任务”进入当前任务；
- 游戏中按 `Esc` 打开暂停菜单，再按一次返回任务；
- 暂停菜单支持继续、设置、重新开始、返回主菜单和退出；
- 设置点击“应用并保存”后写入本机 `PlayerPrefs`，下次启动自动恢复。

## 视觉方向

- 主菜单采用移动巨构工程终端风格，使用深蓝底、青色系统状态与琥珀色任务强调；
- 背景包含低透明度网格、扫描线和边缘状态光，动画使用未缩放时间，暂停时仍保持反馈；
- 主菜单左侧展示巨构、冷却舱与终端链路状态，右侧集中任务操作；
- 暂停菜单使用同一结构，并明确显示任务冻结和本地输入隔离状态；
- 设置页使用音频总线、光学/输入和显示阵列三个控制区，统一按钮、滑轨、开关和选中态。

## 当前设置项

- 音频：主音量、音乐音量、音效音量；
- 控制：鼠标灵敏度、视野范围、反转 Y 轴；
- 画面：分辨率、全屏窗口、Unity 画质预设、垂直同步和帧率上限。

主音量通过 `AudioListener` 统一控制；BGM 与音效拥有独立倍率。打开任一菜单时会禁用移动、观察、上下文交互和工具输入，并隐藏准星与任务提示，避免菜单操作穿透到玩法。

## 当前边界

界面使用项目现有的轻量 IMGUI 表现，以验证流程与参数边界。后续确定正式视觉规范后可以替换为 UI Toolkit 或 UGUI，而无需修改设置数据和应用逻辑。
