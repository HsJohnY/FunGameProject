# M3-6 网络切片最终验证

## 功能范围

- 直接 IPv4/端口监听主机与客户端。
- 玩家生成、所有权、移动和颜色同步。
- 工具位、共享任务物、物理抛放和占用同步。
- 主机权威维修事故完整闭环。
- 会话停止、断线、重连和对象清理。
- MVP 文字聊天：`F3` 显示/隐藏并自动聚焦输入框，服务器转发，单条最多 80 字。
- 聊天输入期间关闭移动、交互和 `Q` 抛放；关闭面板时最近消息仍显示 8 秒。
- 网络诊断：`F2` 显示连接数、生成对象数和客户端 RTT。

## 双进程验收

1. 使用 Windows Development Build 启动两个独立进程。
2. 主机和客户端通过 `127.0.0.1:7777` 完成连接。
3. 完成一次完整维修事故，并在过程中交换共享管件。
4. 双方分别发送至少两条中文文字消息。
5. 打开 `F2`，记录客户端 RTT、连接人数和生成对象数量。
6. 在事故不同阶段分别测试客户端退出重连与房主退出。
7. 连续运行至少 15 分钟，确认没有持续增长的重复对象或阻塞错误。

## 受控网络条件

- 目标条件 A：RTT 0–100 ms，应保持良好。
- 目标条件 B：RTT 101–200 ms，应仍可完成移动、拾取和维修。
- RTT 超过 200 ms 标记为较差，不在当前 MVP 中实现预测回滚。
- 丢包/抖动使用操作系统或外部网络模拟工具进行，不把编辑器专用模拟器写入运行时代码。

## 退出条件

- 自动测试、Windows Development Build 和双进程冒烟均通过。
- 完整事故链、聊天、断开与重连无阻塞缺陷。
- 不出现 NetworkPrefab、RPC、NetworkVariable 或 NetworkObject 生命周期红色错误。
