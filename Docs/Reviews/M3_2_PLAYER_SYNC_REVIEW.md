# M3-2 玩家生成与移动同步评审

## 本次实现

- 每个连接客户端由 NGO 自动生成一个 `M3_NetworkPlayer`。
- 客户端编号映射到分离的出生位置，避免主机和客户端重叠。
- 只有玩家拥有者启用第一人称输入、摄像机和音频监听器。
- 本地身体隐藏，远端身体以临时胶囊显示。
- 玩家位置与水平朝向使用拥有者权威 `NetworkTransform` 同步。
- `Esc` 可在鼠标锁定时安全停止或断开网络会话。

移动采用拥有者权威仅用于降低好友联机下的输入延迟；工具、事故、战斗和其他关键玩法状态仍计划由主机验证。

## 自动验证

- EditMode：37/37 通过。
- PlayMode：27/27 通过。
- 本阶段未生成 Windows Build。

## 人工验收步骤

1. 使用 Unity 6000.0.82f1 打开 `Assets/Game/Scenes/M3_NetworkSlice.unity`。
2. 通过 Multiplayer Play Mode 或两个编辑器/播放器实例运行场景。
3. 第一端保持默认端口 `7777` 并启动主机。
4. 第二端输入主机 IPv4 与相同端口并加入主机。
5. 确认主机显示两名已连接玩家，双方出生位置不同且各只有一个玩家对象。
6. 分别在两端移动、冲刺、跳跃和转向，确认本端只能控制自己的角色。
7. 确认每一端能看到另一名玩家的胶囊体移动和水平转向，且没有远端摄像机或第二个音频监听器警告。
8. 客户端按 `Esc` 断开，确认主机端远端角色消失。
9. 客户端重新加入，确认只生成一个新角色且仍可正常控制。
10. 主机按 `Esc` 停止，确认双方回到可编辑地址和端口的状态。

## 通过条件

- 每个客户端始终只有一个玩家对象。
- 任何一端都不能控制另一名玩家。
- 远端移动和水平转向连续可辨认，无持续明显跳变。
- 断开和重连不遗留重复角色、摄像机或音频监听器。
- Console 无新增红色错误。

## 本阶段不包含

- 远端视角俯仰与完整角色动画。
- 工具、任务物、拾取和抛放同步。
- 事故、战斗或设备状态同步。
- 网络预测、回滚和反作弊。
