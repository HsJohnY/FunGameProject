## M1-4：固定事故链

按以下顺序执行：

1. 装备密封喷枪，对泄漏点持续按住鼠标左键，直到密封完成；
2. 装备冲击扳手，对机械连接按鼠标左键松开；
3. 拾取替换管件，对损坏管件接口按 `E` 安装；
4. 使用冲击扳手对新管件按鼠标左键紧固；
5. 前往冷却控制台按 `E` 复位。

检查：

- [ ] 顶部“当前目标”始终与下一步一致；
- [ ] 错误工具或越序操作不会推进，并能说明原因；
- [ ] 密封过程有进度反馈，完成后泄漏视觉状态改变；
- [ ] 管件安装后手持位清空，目标进入紧固阶段；
- [ ] 紧固和复位后设备状态出现明确变化。

## M1-5：失败、成功与重置

失败路径：

- [ ] 不处理事故，观察顶部温度持续上升；
- [ ] 温度达到上限后显示事故失败；
- [ ] 失败状态不再继续推进维修动作；
- [ ] 靠近控制台按 `E`，显示“重新开始事故”。

成功路径：

- [ ] 完成完整事故链后显示系统恢复稳定；
- [ ] 成功状态不再继续升温；
- [ ] 靠近控制台按 `E` 可以重新开始。

重置路径：

- [ ] 重置后泄漏点恢复未密封；
- [ ] 机械连接恢复初始状态；
- [ ] 替换管件回到恢复点且可再次拾取；
- [ ] 温度、阶段提示和控制台状态恢复初始值；
- [ ] 连续重置三次没有残留状态、重复日志或丢失任务物。
