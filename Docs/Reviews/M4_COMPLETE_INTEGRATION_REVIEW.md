# M4 多人完整整合候选评审

## 候选内容

- 同一场景内提供主菜单、直接 IPv4 联机、玩家同步、文字聊天和三舱空间。
- 第一章为主机权威冷却维修：双点诊断、三工具维修、共享管件、温度与统一重置。
- 第一章完成后同步开启配电舱；五个继电器各需三步桥接，同时处理一组干扰体。
- 第二章全部完成后同步开启风暴核心舱；三波敌人逐步增加，末名重甲敌人需桥接器破盾。
- 每波结束后由玩家在风暴核心校准终端按 `E` 写入结果；第三波后显示完整切片完成。
- 房间门禁、章节目标、敌人生命、位置、核心完整度和成功结果均由主机决定。

## 操作

- `WASD` 移动，鼠标观察，`Shift` 冲刺，`Space` 跳跃。
- 对工具架、诊断点、任务物、安装点和控制台按 `E`。
- 工具动作使用鼠标左键；`Q` 抛下手持管件。
- `F1` 会话面板，`F2` 网络诊断，`F3` 文字聊天。

## 双进程完整流程

1. 编辑器启动主机，Windows 构建作为客户端连接 `127.0.0.1:7777`。
2. 合作完成第一章冷却维修，确认两端目标一致，配电舱门同时开启。
3. 使用桥接器分别完成五个继电器的三步校准，并使用任意工具清除干扰体。
4. 确认风暴核心舱门开启；完成三波防卫，每波后在校准终端按 `E`。
5. 对重甲敌人先使用桥接器破盾，再用任意工具造成伤害。
6. 确认双方显示“远征切片完成”，期间不存在重复生成、未注册预制体或本地假进度。
7. 额外验证聊天输入不会触发工具/抛弃动作，客户端断开重连能读取主机当前章节。

## 失败与一致性

- 敌人抵达章节核心后会降低完整度；降至零时由主机重置当前战斗，不回退已完成章节。
- 错误工具无法穿透重甲护盾，客户端远距离请求不会生效。
- 任意客户端不能单独开门、生成敌人或修改章节结果。

## 当前非目标

- Relay/邀请码、距离语音、个人等级与技能树仍属于后续计划。
- 当前敌人使用清晰的低模联网代理；更复杂动画、导航和美术反馈属于打磨阶段。
