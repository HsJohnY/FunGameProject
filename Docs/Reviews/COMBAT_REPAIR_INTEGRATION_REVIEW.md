# 维修防卫集成候选评审

## 当前状态

- Unity 版本：`6000.0.82f1`；
- 候选场景：`Assets/Game/Scenes/Combat_CoolingBayIntegration.unity`；
- `M1_CoolingBay` 已补齐三工具/三任务最小教学，候选场景继续由独立生成器复制并扩展战斗内容；
- EditMode：37/37 通过；PlayMode：28/28 通过；
- Windows Development Build：成功；真实播放器 `--combat-repair-smoke` 退出码为 0；
- 人工节奏、手感和教学可读性：待项目推动者评审。

## 本轮验证命题

战斗不取代维修。最小 demo 以机械连接、管道泄漏和断路控制节点分别教授冲击扳手、密封喷枪和线路桥接器；泄漏处理后出现一次有限干扰，三件维修工具都能以不同方式支援防卫。人工评审应重点判断工具边界是否清楚，以及防卫是否仍像维修中的短促插曲。

## 已实现内容

- 冲击扳手使用 0.38 秒冷却和简单位移挥动；命中干扰体时有闪白、形变、本地短顿帧、轻微镜头震动和程序化占位音；
- 普通干扰体可被任意工具消灭，不要求日常清杂按工具克制反复换装；
- 冲击扳手以高单体伤害和强击退快速处理孤立目标；
- 密封喷枪持续喷覆会造成范围伤害、降低移动速度并逐步推离设备，独立战斗沙盒用五只低血量虫群验证其清群价值；
- 线路桥接器以离散脉冲造成过载伤害、短暂瘫痪并中断攻击蓄力；战斗沙盒中的护盾精英需要先用桥接器短路，随后其他工具也能继续输出；
- 断路控制节点要求依次执行“检测端点、连接旁路、验证回路”，与扳手的离散机械操作和喷枪的连续覆盖区分；
- 左下角工具腰带 HUD 显示当前主工具、独立手持物和三件工具的维修/防卫用途；工具仍只能从工具架换取，不提供传统格子背包或远程切换；
- 敌人接触设备后先进入明显蓄力，蓄力期间变为警告色并通过跳动连线指向受威胁设备，然后才结算伤害；
- 辅助设备有三段世界空间完整度灯和受损/离线警报，不使用传统敌人或玩家血条；
- 直线干扰体直接接近设备；侧袭附着体先绕到设备一侧，生命更低、移动更快；
- 密封阶段完成后同时激活两名干扰体。设备每次受击都会抬升冷却事故温度，设备离线会统一触发事故失败；
- 地面橙色标记从扳手架引向敌人路线和被保护设备，承担“扳手架 → 敌人 → 设备”的无文字引导；
- 遭遇、敌人和设备均发布只读状态事件，供 M3-2 之后接入主机权威同步；本轮未实现或宣称多人战斗同步。

## 启动方式

### Unity 编辑器

1. 使用 Unity Hub / Unity `6000.0.82f1` 打开工程；
2. 打开 `Assets/Game/Scenes/Combat_CoolingBayIntegration.unity`；
3. 点击 Play。

如需重新生成候选场景，执行 `FunGame > Combat > 生成维修防卫集成场景`。生成器读取 M1 源场景并另存为候选场景，不覆盖源场景。

### Windows 开发构建

运行 `Builds/CombatRepair-Windows/FunGame-CombatRepair.exe`。如需重新构建，执行 `FunGame > Combat > 构建维修防卫 Windows 开发版本`。

## 人工成功路径

1. 从右侧架上取得密封喷枪，完成泄漏点密封；
2. 观察维修目标切换，同时确认两名干扰体开始接近辅助设备；
3. 尝试用密封喷枪范围喷覆、减速并推离干扰体；
4. 从右侧工具架换取线路桥接器，确认电击会瘫痪并中断敌人蓄力；
5. 换取冲击扳手，用高单体重击和击退清除两名敌人；
6. 分别确认机械连接、泄漏点和断路控制节点只接受对应工具；
7. 继续安装替换管件、紧固并在控制台复位。

通过检查：

- [ ] 不阅读说明也能理解敌人正在威胁哪个设备；
- [ ] 攻击蓄力足以让玩家在设备掉完整度前作出反应；
- [ ] 扳手挥动、冷却、闪白、顿帧、轻震和声音共同形成清晰但不过度的命中反馈；
- [ ] 喷枪范围清群、桥接器电击/瘫痪和扳手单体重击在动作、音高、敌人颜色和效果上容易区分；
- [ ] 三个任务分别能用“紧固、密封、桥接”描述，不会都被理解成同一种修复进度条；
- [ ] 工具腰带 HUD 能解释当前装备与手持物，同时不会让人误以为三件工具都在背包里；
- [ ] 敌人剩余状态可从颜色与形变理解，不需要传统血条；
- [ ] 能从路线和外形区分直线敌人与侧袭附着敌人；
- [ ] 防卫段约 30–60 秒，结束后能自然回到维修，不会误以为关卡已经完成；
- [ ] 控制台对成功、失败和重新开始的提示明确；
- [ ] Console 没有项目代码异常或持续错误。

## 人工失败与重置路径

1. 完成密封并触发干扰后，不处理敌人；
2. 确认设备在每次攻击前都有蓄力与连线提示，受击后温度上升；
3. 等待辅助设备离线，确认冷却事故进入失败状态；
4. 前往冷却控制台按 `E` 重新开始；
5. 确认维修阶段、温度、辅助设备、两名敌人和触发状态全部恢复。
