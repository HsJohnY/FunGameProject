# M4-2 联网合作维修评审

## 本阶段实现

- 在 `M4_CoopThreeChapterDemo` 的第一舱接入一套主机权威冷却事故。
- 两名玩家共享诊断结果、桥接进度、密封进度、维修阶段、温度和成功/失败状态。
- 三种工具均可联网装备与放回；需要工具的动作统一使用鼠标左键。
- 替换管件由服务器生成，同一时间只能由一名玩家持有，可抛放、交接、安装和重置。
- 服务器验证玩家距离、当前阶段、所持工具和任务物，客户端不能靠本地状态越序推进。

## 人工核验准备

1. 用 Unity 打开 `Assets/Game/Scenes/M4_CoopThreeChapterDemo.unity`，确认 Console 没有红色编译错误。
2. 启动编辑器作为主机，再启动最新 M4 Windows 开发版本作为客户端；两端使用同一端口连接。
3. F1 显示或隐藏会话面板，F2 显示网络诊断，F3 打开文字聊天。

## 完整合作流程

建议双方分工操作，并在每一步观察两端顶部事故提示是否同步：

1. 两名玩家分别对压力表、冷却泵检查面板按 `E`，完成双点诊断。
2. 任意玩家从线路桥接器工具架按 `E` 取工具，对紫色联锁箱点击左键三次。
3. 从密封喷枪工具架取工具，对泄漏点点击左键四次，完成密封。
4. 从冲击扳手工具架取工具，对机械连接件点击左键，松开旧连接。
5. 另一名玩家对共享替换管件按 `E` 拾取并搬到安装接口，再按 `E` 安装。
6. 使用冲击扳手再次点击机械连接件，紧固新管件。
7. 对压力表按 `E` 验证压力，再对控制台按 `E` 复位冷却泵。
8. 两端都应显示事故成功，且阶段、温度和进度一致。

## 边界与恢复核验

- 尝试跳过当前步骤、使用错误工具或离目标过远操作，事故不应推进。
- 一人持有管件时，另一人不能同时拾取；按 `Q` 抛下后另一人应能接手。
- 成功或温度超限后，在控制台按 `E` 应统一重置事故和管件位置。
- 客户端中途断开并重连后，应读取主机当前事故状态，不应另起一套本地进度。
- 房主停止会话后，双方应安全退出且不残留联网对象。

## 自动验证

- EditMode：76/76 通过。
- PlayMode：37/37 通过。
- PlayMode 已真实启动主机，并确认唯一聊天对象、冷却事故和共享替换管件均从已注册网络预制体生成。

## 本阶段边界

- 当前只联网化第一套冷却维修循环；三章关卡推进、后续冷却变式与舱门联动仍待整合。
- 敌人、设备受击、武器伤害与击退仍保持冻结，统一留到 M4-3。
- 仍使用直接 IPv4；Relay、邀请码和距离语音不在本阶段范围。
