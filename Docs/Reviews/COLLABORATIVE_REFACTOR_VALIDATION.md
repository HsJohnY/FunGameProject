## 交付内容

- 根目录 `AGENTS.md` 明确要求任何 agent 在编辑前完整阅读规范，并检查 Git 状态、模块权威来源和所有权边界。
- 单人/合作共用的主场景由 41,102 行缩减为 3,067 行，以 Prefab 实例和显式连接为主。
- 新模块目录包含 107 个 Prefab，包括玩家、敌人、实体、事故、遭遇、UI、会话和独立外观资源。
- 配置目录包含 48 个 ScriptableObject 资产：35 个敌人配置、1 个冷却事故配置、2 个工具冷却配置、7 个遭遇配置和3 个环境场景定义。
- 冷却舱、配电舱、风暴核心的静态环境采用三个 Additive Scene；业务就绪前完成加载，切换模式时清理环境。
- 网络模板通过稳定内容 ID 解析；敌人登记从所属遭遇的显式引用收集，新增敌人无需再修改主场景里的总表。
- 普通 M4/单人构建消费现有资产；旧整图生成器在模块化工作区拒绝运行。环境生成器不会重新保存无变化的场景。
- 提供仓库本地 UnityYAMLMerge 初始化脚本；Unity YAML 的空值行保留引擎序列化格式。PlayerSettings 的一个空值尾部空格随本次规范化保存，避免之后重复出现引擎自动补写差异。

## 本轮边界

Additive Scene 当前只承载静态环境与碰撞。联网业务对象仍由现有 NGO 主机会话动态生成；未引入网络场景流式加载或动态卸载。实体根部供受击逻辑使用的 Renderer 和碰撞仍属于玩法 Prefab，附属外观及第一人称工具模型已独立。

历史 M0/M1/M3 和战斗验证场景保留用于回归；正式内容以模块源资产为准。配置中的隐藏旧字段仅用于历史场景兼容，不能作为新内容调参入口。

自动化验证覆盖运行与同步正确性，本轮没有代替真人重新进行完整多人体验验收。

复现命令和编辑入口见 [模块化协作架构](../COLLABORATIVE_ARCHITECTURE.md)；编辑前先读 [AGENTS.md](../../AGENTS.md)。
