# M1-3 工具与任务物人工评审

状态：等待人工评审

## 人工测试发现的问题（待处理）

### M1-3-ISSUE-01：装备工具后无法恢复空手

- 现象：玩家取得工具后只能在冲击扳手与密封喷枪之间替换，无法主动清空主工具位；
- 影响：输入与装备边界不完整，是否需要“收起工具”操作尚未确定；
- 当前处理：只记录，不修改代码；恢复开发后先评估空手是否为必要状态，以及是否应复用现有按键；
- 修复：对已装备工具所在的工具架再次按 `E`，即可将其放回并恢复空手；
- 状态：已修复，等待人工复测。

### M1-3-ISSUE-02：装备工具后拾取物块出现画面异常

- 现象：手持工具时再拾取物块，物块的第一人称显示出现问题；
- 已确认：拾取与携带的实际逻辑仍然正常，问题仅出现在画面表现；
- 初步关注：主工具模型与手持物模型可能存在显示位置、遮挡或层级冲突；
- 当前处理：只记录，不修改代码；恢复开发后需要复现并确认具体视觉表现；
- 修复：携带物进入第一人称手持位时缩小并稍作旋转，抛出时恢复原始尺寸，避免与左侧工具模型穿插和大面积遮挡；
- 状态：已修复，等待人工复测。

## 本阶段验证范围

M1-3 只验证主工具位、工具语义、替换管件携带和受控物理抛放。密封目标和机械连接暂不推动正式故障流程；弹药、耐久、蓄力、伤害与正式动画均不在本阶段。

## 启动方式

1. 使用 Unity `6000.0.38f1` 打开项目；
2. 双击 `Assets/Game/Scenes/M1_CoolingBay.unity`；
3. 点击 Play；
4. 评审结束后停止 Play，不保存运行时位置。

## 新增操作

| 输入 | 行为 |
| --- | --- |
| `E` | 从工具架换取工具，或拾取替换管件 |
| 鼠标左键 | 使用当前主工具执行准星显示的动作 |
| `Q` | 按当前观察方向抛出手持管件 |

## 检查清单

- [ ] 在右侧工具架看向冲击扳手或密封喷枪时，`E` 提示能明确说出将装备哪件工具；
- [ ] 玩家同一时间只显示一件主工具，再次取用会直接替换而不是增加背包物品；
- [ ] 冲击扳手对机械连接显示“松开/紧固”，鼠标左键会切换状态与颜色；
- [ ] 密封喷枪对泄漏样例显示“密封”，完成后明确显示已经处理；
- [ ] 使用错误工具时提示“需要冲击扳手”或“需要密封喷枪”，且目标状态不改变；
- [ ] 替换管件仍占独立手持位，携带管件不清除当前主工具；
- [ ] 平视按 `Q` 时管件受控地向前抛出，不会异常飞远；
- [ ] 向上观察按 `Q` 时管件形成更高的抛物线，向下观察时轨迹相应降低；
- [ ] 抛出的管件落地后恢复碰撞，并可再次拾取；
- [ ] Console 没有进入 `Assets/Game` 调用栈的红色错误。

任务物跌出场景后的恢复已由 PlayMode 测试覆盖，本轮无需手动修改 Transform 或编写代码。

## 请重点反馈

- 两种工具的名称、模型颜色和动作词是否足以避免“该用哪个工具”的困惑；
- 工具显示位置是否遮挡视野；
- 左键使用工具、`E` 取物、`Q` 抛物的职责是否直观；
- 抛物力度是否过强、过弱，或向上抛出的弧线是否不明显；
- 提示是否稳定，有无工具提示与拾取提示互相覆盖。
