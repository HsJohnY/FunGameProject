# M3-3A 联网工具位基础评审

## 本次范围

- 网络验证场加入冲击扳手架和密封喷枪架。
- 本地玩家沿用 `E` 上下文交互装备或放回工具，不增加新的操作键。
- 玩家只发送工具切换请求，服务器验证工具类型并写入同步状态。
- 每名玩家的主工具位独立同步，其他客户端能获得一致的装备结果。
- 非拥有者实例不读取交互输入，也不显示重复交互提示。

## 暂不包含

- 工具作用目标和维修结果同步。
- 可拾取任务物、搬运和物理抛放同步。
- 有限工具库存或工具架占用竞争。

上述内容进入 M3-3B/M3-4，避免在验证工具所有权前同时引入物理与事故权威问题。

## 自动验证

- EditMode：42/42 通过。
- PlayMode：27/27 通过。
- 未生成 Windows Build。

## 联合人工验收

1. 先按 M3-2 清单建立主机与客户端，并确认两端角色可移动且颜色不同。
2. 任一玩家靠近左侧高窄的冲击扳手架，准星对准后按 `E`。
3. 确认提示由“装备冲击扳手”变为“放回冲击扳手”，第一人称占位模型出现。
4. 同一玩家再按 `E` 放回，确认占位模型消失。
5. 前往右侧较宽的密封喷枪架装备，确认它会替换当前工具而不是增加第二个工具位。
6. 两名玩家分别装备不同工具，确认双方操作互不篡改对方主工具位。
7. 反复切换并断开客户端，确认 Console 没有 RPC、所有权或 NetworkVariable 红色错误。
