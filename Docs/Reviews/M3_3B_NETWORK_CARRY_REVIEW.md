# M3-3B 共享任务物拾取与抛放评审

## 本次范围

- 主机启动后生成唯一的共享替换管件。
- 玩家沿用 `E` 拾取，沿用 `Q` 抛放，不增加新按键。
- 任务物始终由服务器拥有；客户端只通过自己的玩家对象提交请求。
- 服务器验证拾取距离、玩家手持位和物品占用，阻止两人同时持有同一物品。
- 手持关系、世界位置和抛物线物理结果同步到其他客户端。
- 任务物跌出验证场后由服务器恢复到初始位置。

## 暂不包含

- 将管件安装到事故设备。
- 事故阶段、维修结果和战斗状态同步。
- 客户端预测的拾取动画或复杂网络物理补偿。

这些内容分别进入 M3-4 与后续表现打磨，当前只验证共享物品的权威边界。

## 人工验收重点

1. 主机启动后，确认场地中央只出现一个长方体共享管件。
2. 任一玩家靠近后按 `E` 拾取，另一端应看到管件随该玩家移动。
3. 另一名玩家同时尝试拾取，确认不会复制或抢走已被持有的管件。
4. 持有者按 `Q`，确认管件按视角方向形成可见抛物线并在双方位置一致。
5. 另一名玩家拾取刚落地的管件，确认所有权流程可以交接。
6. 将管件抛出围墙或场景下方，确认服务器将其恢复到中央生成点。
7. 持有管件时断开客户端，确认主机没有残留占用、重复物体或红色错误。
