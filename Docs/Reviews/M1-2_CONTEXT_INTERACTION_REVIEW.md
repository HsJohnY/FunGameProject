# M1-2 上下文交互人工评审

状态：等待项目推动者评审

## 目的

只判断准星目标、动作提示和少量逻辑输入是否清晰可靠。控制台与测试管件是接口代表用例，不评价维修链、工具手感或正式 UI 美术。

## 启动方式

1. 使用 Unity `6000.0.38f1` 打开项目；
2. 双击 `Assets/Game/Scenes/M1_CoolingBay.unity`；
3. 点击 Play；
4. 评审结束后停止 Play，不保存运行时位置。

## 新增键位

| 输入 | 行为 |
| --- | --- |
| `E` | 执行准星当前显示的上下文动作 |
| `Q` | 丢下当前手持物；空手时无副作用 |

M1-1 的移动、观察、冲刺、跳跃和 `Esc` 保持不变。

## 检查清单

- [ ] 屏幕中央始终有可识别但不过度遮挡的准星；
- [ ] 远离对象、看向墙壁或被物体遮挡时不显示错误动作；
- [ ] 进入约 3 米范围并看向小型橙色测试管件时显示“`[E] 拾取 · 测试管件`”；
- [ ] 按 `E` 后管件稳定显示在镜头右下方，不抖动、不推挤玩家；
- [ ] 按 `Q` 后管件落到玩家前方，恢复碰撞并可以再次拾取；
- [ ] 看向橙色控制台时显示明确的“启动”或“关闭”，而不是含糊的“修复”；
- [ ] 连续按 `E` 时控制台颜色和下一动作文字同步切换；
- [ ] 按 `Esc` 释放鼠标后准星动作提示消失，场景交互暂停；
- [ ] 没有因准星擦过邻近物体而明显选中远处或被遮挡目标；
- [ ] Console 没有进入 `Assets/Game` 调用栈的红色错误。

## 请记录

- 准星大小、颜色和位置是否容易识别；
- 提示文字是否太大、太小、出现过早或闪烁；
- 交互距离是否过远或必须贴得太近；
- `E` 与 `Q` 的职责是否容易记忆；
- 手持管件是否遮挡关键视野；
- 任何误选、无响应、重复执行、穿模或物体飞出的步骤；
- 若出现 Assertion，确认是否与 `KI-001` 的 TextCore/Inspector 调用栈相同。

## 当前已知限制

- 提示层使用临时 IMGUI，正式 UI 技术与视觉样式尚未确定；
- 只有一个手持位，没有背包、安装位或任务物恢复点；
- 控制台切换不影响故障状态，测试管件也不是最终替换管；
- 工具与连续操作从 M1-3 开始实现。
