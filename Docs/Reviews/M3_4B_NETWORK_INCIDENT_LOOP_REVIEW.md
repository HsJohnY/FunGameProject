# M3-4B 联网维修事故闭环评审

## 完整流程

1. 两端连接后确认右上角事故阶段与温度一致。
2. 玩家装备密封喷枪，在泄漏站连续执行四次 `E` 密封。
3. 任一玩家换冲击扳手，在连接站按 `E` 松开连接。
4. 任一玩家拾取中央共享替换管件，搬到安装接口并按 `E` 安装。
5. 玩家使用冲击扳手回到连接站按 `E` 紧固。
6. 任一玩家在控制台按 `E` 完成泵复位。
7. 双端应同时显示 `Stabilized / Succeeded`。
8. 再次操作控制台，事故回到初始阶段，共享管件恢复到中央生成点。

## 权威边界

- 客户端不能直接写事故阶段、温度、工具位或任务物状态。
- 服务器验证玩家身份、距离、阶段、工具和手持任务物。
- 安装管件与推进事故阶段在同一次服务器请求中完成。
- 重置事故时服务器统一清除手持占用并恢复共享任务物。

## 异常检查

- 两人同时操作同一目标不会跳过阶段。
- 未装备正确工具、未持有管件或越序操作不会推进阶段。
- 持有管件时事故失败并重置，不会留下无法拾取的管件。
- 客户端断开后主机仍可继续或重置事故。
- Console 无 RPC、NetworkVariable、NetworkObject parenting 红色错误。
