# M3-4A 主机权威事故状态评审

## 本次范围

- 事故阶段、密封进度、温度和运行结果只由服务器写入。
- 客户端通过场景网络交互站提交维修请求。
- 服务器验证请求发送者、交互距离、当前阶段和已装备工具。
- 双端右上角 HUD 显示同一份同步事故状态。
- 密封喷枪累计四次密封后进入松开连接阶段。
- 冲击扳手只在松开或紧固阶段有效。
- 控制台只在泵复位阶段有效；事故成功或失败后可用于重新开始。

## 当前阶段边界

M3-4A 在“安装替换管件”阶段暂停。共享管件消耗、安装表现和后续紧固/复位闭环进入 M3-4B，避免在第一步同时调试事故状态和物品安装事务。

## 本轮不要求立即验收

先确认 Unity 编译并重新生成场景。完成 M3-4B 后，再联合验证完整双人事故链。
