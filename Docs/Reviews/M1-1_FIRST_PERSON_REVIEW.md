# M1-1 第一人称移动人工评审

状态：等待项目推动者评审

## 目的

只判断第一人称移动、观察和最小冷却舱空间是否具备继续开发交互系统的基础。泵、控制台和货架仍是不可交互的颜色占位体，不评价正式美术或维修玩法。

## 启动方式

1. 使用 Unity `6000.0.38f1` 打开项目根目录；
2. 双击 `Assets/Game/Scenes/M1_CoolingBay.unity`；
3. 点击 Play；
4. 结束后再次点击 Play 停止，不要保存运行时产生的临时位置。

## 当前键位

| 输入 | 行为 |
| --- | --- |
| `W/A/S/D` | 移动 |
| 鼠标 | 观察 |
| 左 `Shift` | 按住冲刺 |
| `Space` | 跳跃 |
| `Esc` | 锁定或释放鼠标 |

## 检查清单

- [ ] 前后左右移动方向与镜头朝向一致；
- [ ] 同时按两个方向不会获得异常的斜向速度优势；
- [ ] 按住左 `Shift` 能明确感到速度提高，但不会快到失去室内控制；
- [ ] 跳跃高度足以越过低矮障碍感，但不会产生漂浮感；
- [ ] 上下观察不会翻转镜头；
- [ ] 玩家不会穿过墙、地板、泵、控制台或货架占位体；
- [ ] `Esc` 可以释放鼠标，再按一次可以恢复观察；
- [ ] 连续移动两分钟没有持续 Console 红色错误。

## 请记录

- 鼠标是否太快或太慢；
- 行走、冲刺、跳跃分别是否太弱或太强；
- 是否发生眩晕、不适、卡墙、穿模或镜头异常；
- 冷却舱尺度是否显得过大、过小或难以辨认方向；
- Unity Console 中第一条红色错误及其完整堆栈（若有）。

## 当前已知限制

- 暂无准星、交互提示、设置界面、声音、蹲伏和控制器支持；
- 键位暂由代码中的 Input System 适配器创建，正式重绑定延后；
- 所有设备与货架只是空间占位，M1-2 后才逐步具有交互行为。
