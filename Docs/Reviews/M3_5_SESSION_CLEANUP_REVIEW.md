# M3-5 会话清理评审

## 清理规则

- 停止会话后必须等待 NGO 的客户端/服务器停止回调，再恢复地址输入。
- 房主正常停止时保留最后一帧消息队列，优先发送 Despawn 与断开通知。
- 每轮服务器停止后，任务物与事故生成器明确清除旧对象引用。
- 玩家持有任务物断线时，服务器释放手持占用并保留可继续使用的任务物。
- 会话结束后鼠标恢复可见且不再锁定。

## 验证序列

1. 主机和客户端连接，客户端拾取共享管件后直接断开。
2. 主机确认客户端角色消失，管件没有复制或永久占用。
3. 客户端重新加入，确认只生成一个角色且可以继续拾取管件。
4. 主机停止会话，确认客户端回到未连接状态并可修改地址。
5. 使用同一端口连续执行三轮“启动—连接—停止—重连”。
6. 每轮确认只有一个事故对象、一个共享管件和每客户端一个玩家对象。
7. Console 不应出现重复 Spawn、未注册 Prefab、无效父对象或已销毁对象引用错误。
