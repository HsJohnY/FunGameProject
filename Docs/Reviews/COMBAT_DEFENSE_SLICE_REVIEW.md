## 生成与启动

1. 使用 Unity `6000.0.82f1` 打开工程；
2. 打开 `Assets/Game/Scenes/Combat_DefenseSandbox.unity`；
3. 点击 Play；如需重新生成场景，执行菜单 `FunGame > Combat > 生成基础防卫场景`。

## 成功路径

1. 在出生点左侧工具架对准冲击扳手，按 `E` 取得；
2. 接近正在向冷却控制单元移动的紫色干扰体；
3. 准星出现“击退”后点击鼠标左键；
4. 共完成三次命中。

通过检查：

- [ ] 密封喷枪对准敌人时明确提示需要冲击扳手；
- [ ] 每次命中都会降低敌人状态并产生可见击退；
- [ ] 第三次命中后遭遇立即成功，不等待固定波次或计时；
- [ ] 设备完整度在敌人接触后下降，但战斗信息不会遮蔽防卫目标；
- [ ] 成功后敌人停止移动和干扰。

## 失败与重置路径

1. 不处理敌人，等待其接近设备；
2. 观察设备完整度随干扰下降；
3. 设备归零后确认防卫失败；
4. 前往防卫训练控制台按 `E`；
5. 分别从成功和失败状态至少重置一次。

通过检查：

- [ ] 失败原因明确指向设备离线，而不是玩家传统死亡；
- [ ] 失败后敌人停止继续攻击；
- [ ] 重置恢复设备完整度、敌人生命、出生位置和碰撞；
- [ ] 重置后可以再次完成成功或失败闭环；
- [ ] Console 没有项目代码异常或持续错误。
