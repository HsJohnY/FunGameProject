# 测试策略

## 三层验证

1. **EditMode**：纯规则、数值边界、状态转换、序列化与工具代码，快速执行。
2. **PlayMode**：需要场景、物理、Unity 生命周期或输入链路的集成行为。
3. **手工试玩**：趣味性、手感、可理解性、视觉和音频反馈，记录观察而非只记录“通过”。

## 完成定义

- 需求有可观察的验收条件。
- 相关自动化测试通过；无法自动化的部分有手工验收记录。
- Unity Console 无新增错误。
- `PROJECT_STATUS.md` 已更新。
- 变更已提交；里程碑已创建标签和外部 Git bundle 备份。

## 原型期质量边界

原型允许临时素材和低保真表现，但不允许无法复现的核心规则、持续报错、把生成目录提交到 Git，或没有恢复点的大范围改动。
