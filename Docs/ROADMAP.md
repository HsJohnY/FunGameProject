# 路线图

路线图采用阶段门禁，而不是用未经验证的日期承诺功能。

## 阶段 0：发现与立项

交付：Game Brief、范围边界、初步风险、原型验收条件。

## 阶段 1：可玩原型（当前）

分为技术准备、单机核心灰盒和首次玩法评审。交付：可运行的冷却舱核心循环、最小输入与反馈、自动测试、至少 3 份首次试玩记录，以及继续、修改或停止结论。

## 阶段 2：垂直切片

先完成双人网络切片，再扩展为 2–4 人功能 MVP 和 30–45 分钟代表章节。交付：代表最终结构的一段完整体验、架构基线和内容生产流程。

## 阶段 3：制作与打磨

交付：完整 MVP 内容、可重复构建、回归测试、性能预算。

## 阶段 4：发布候选

本练手项目对应“可分享版本”。交付：好友可独立运行的 Windows 构建、游玩清单、已知问题、版本标签与可恢复备份。

详细小阶段、运行门禁和人工审查规则见 `MVP_DEVELOPMENT_PLAN.md`。
